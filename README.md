# Binge.

**Your next obsession** — hand-picked Hindi & English movies and web series with IMDb ratings, at [binge.shanuva.com](https://binge.shanuva.com).

A zero-build static site: open `index.html` and it works. No framework, no bundler, no server required.

## Features

- **Hindi-first catalogue** — ~135 curated titles, weighted toward Bollywood films and Indian web series (Scam 1992, Panchayat, Gullak, 12th Fail…), plus the best of English cinema and TV.
- **Highly Rated filter** — one toggle to show only IMDb **7+**.
- **My Genres** — visitors pick up to 4 favourite genres (saved in `localStorage`); the site opens with a "Picked for you" rail matched to them.
- **Filters** — Movies/Series, Hindi/English, genre chips (multi-select), year/decade (2026 back to pre-1990 classics), full-text search.
- **Sorting** — All-time best (IMDb), newest, oldest, A–Z.
- **Auto-sync** — a script + GitHub Action keep the catalogue fresh with the latest releases.
- **Posters & detail popup** — every card shows the real poster; clicking opens a cinematic popup with synopsis, cast, director, runtime and platform. Clicking any rating badge jumps straight to the title's IMDb page.

## Project layout

```
index.html            the site
css/style.css         design system (retro-marquee dark theme)
js/app.js             filtering, sorting, personalisation, detail popup
data/titles.js        the catalogue (regenerated by sync/enrich)
scripts/sync.mjs      pulls latest titles from TMDB (+ OMDb for IMDb ratings)
scripts/enrich.mjs    adds posters, cast, director, runtime, IMDb ids
.github/workflows/    daily sync automation
.env                  local API keys (gitignored — never commit)
```

## Run locally

```bash
python3 -m http.server 8080
```

Then open http://localhost:8080. (Opening `index.html` directly also works.)

## Keeping the catalogue fresh

The sync script asks TMDB for the latest Hindi movies/series (plus top English releases) and merges them into `data/titles.js` — curated entries are never overwritten.

```bash
TMDB_API_KEY=your_key node scripts/sync.mjs
```

- **TMDB key** (required, free): themoviedb.org → Settings → API → v3 key.
- **OMDb key** (optional, free): omdbapi.com — when set, new titles get *true IMDb ratings* instead of TMDB scores, and existing ratings are refreshed:

```bash
TMDB_API_KEY=xxx OMDB_API_KEY=yyy node scripts/sync.mjs
```

### Enriching titles (posters, cast, IMDb links)

`scripts/enrich.mjs` fills in `poster`, `desc`, `cast`, `director`, `runtime` and `imdb` for every title — posters and synopses come from Wikipedia, credits and IMDb ids from Wikidata (both free, no key), and anything still missing is answered by **Gemini 2.5 Flash with Google Search grounding**:

```bash
set -a && source .env && set +a && node scripts/enrich.mjs --only-missing
```

Put your `GEMINI_API_KEY` in `.env` (see the template — it is gitignored on purpose; never commit API keys). Free-tier Gemini allows ~10 requests/min, and the script throttles itself accordingly.

### Automatic daily sync

Push this repo to GitHub, then add `TMDB_API_KEY` and `GEMINI_API_KEY` (and optionally `OMDB_API_KEY`) under **Settings → Secrets and variables → Actions**. The included workflow ([.github/workflows/sync.yml](.github/workflows/sync.yml)) syncs daily at 07:00 IST, enriches any new titles, and commits the updated catalogue — your host redeploys automatically.

## Deploying to binge.shanuva.com

Any static host works. Recommended: **Cloudflare Pages** (free, fast in India):

1. Push this folder to a GitHub repo.
2. Cloudflare Pages → Create project → connect the repo → no build command, output dir `/`.
3. Custom domains → add `binge.shanuva.com`.
4. In your `shanuva.com` DNS, add a `CNAME` record: `binge` → `<project>.pages.dev`.

Netlify and Vercel work identically (also free). GitHub Pages works too — point the `binge` CNAME at `<user>.github.io`.

## Editing the catalogue by hand

Each entry in `data/titles.js` is one line:

```js
{ title: "Panchayat", type: "series", year: 2020, lang: "hi",
  genres: ["Comedy", "Drama"], rating: 8.8, platform: "Prime Video",
  plot: "An engineering grad becomes secretary of remote Phulera village." }
```

`type` is `movie`/`series`, `lang` is `hi`/`en`. Genres, stats, and filters all derive automatically.
